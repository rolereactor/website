## Complete Command Reference

### General Commands

- [`/core`](./commands/general/core) - View your Core balance and credit store options
- [`/help`](./commands/general/help) - Access help and information about bot commands
- [`/premium`](./commands/general/premium) - View Pro Engine premium features and limits
- [`/stats`](./commands/general/stats) - View bot statistics and command usage
- [`/ping`](./commands/general/ping) - Verify bot latency and connection status
- [`/invite`](./commands/general/invite) - Retrieve the bot invite link
- [`/support`](./commands/general/support) - Access the support server link
- [`/avatar`](./commands/general/avatar) - Generate AI-powered avatars with custom prompts
- [`/8ball`](./commands/general/8ball) - Ask the magic 8ball a question
- [`/poll create`](./commands/general/poll) - Create a new poll using interactive form
- [`/level`](./commands/general/level) - View your level and experience
- [`/leaderboard`](./commands/general/leaderboard) - View the server experience leaderboard
- [`/rps`](./commands/general/rps) - Challenge someone to Rock Paper Scissors
- [`/serverinfo`](./commands/general/serverinfo) - Display detailed information about the server
- [`/userinfo`](./commands/general/userinfo) - Display detailed user profile and warning history
- [`/vote`](./commands/general/vote) - Vote for the bot on top.gg and earn rewards
- [`/wyr`](./commands/general/wyr) - Get a random "Would You Rather" question

### Admin Commands

- [`/starboard`](./commands/admin/starboard) - Configure community starboard channel, emoji, and thresholds
- [`/giveaway`](./commands/admin/giveaway) - Create and manage server giveaways with role weighting
- [`/ticket`](./commands/admin/ticket) - Manage the support ticket system, panels, and transcripts
- [`/role-bundle`](./commands/admin/role-bundle) - Manage reusable role bundles
- [`/role-reactions`](./commands/admin/role-reactions) - Manage self-assignable role selection messages
- [`/moderation`](./commands/admin/moderation) - Timeout, warn, ban, kick, and purge members
- [`/voice-roles`](./commands/admin/voice-roles) - Auto-control users in voice channels based on roles
- [`/temp-roles`](./commands/admin/temp-roles) - Manage temporary role assignments with bulk targeting
- [`/schedule-role`](./commands/admin/schedule-role) - Schedule future role assignments
- [`/welcome`](./commands/admin/welcome) - Configure the welcome system and settings
- [`/goodbye`](./commands/admin/goodbye) - Configure the goodbye system and settings
- [`/xp`](./commands/admin/xp) - Manage the XP system, settings, and level rewards
- [`/automod`](./commands/admin/automod) - Configure auto-moderation filters

### Command Permissions

- **General Commands:** Available to all users
- **Admin Commands:** Require "Manage Roles" or "Manage Server" permission (varies by command)
