## Usage Examples

<Tabs items={["Status & Vault", "Fuel Vault"]}>
  <Tab value="Status & Vault">
    View server engine status or Guild Vault balance:

    ```bash
    /engine status
    /engine vault
    ```
  </Tab>
  <Tab value="Fuel Vault">
    Deposit Cores into the server's Vault:

    ```bash
    /engine fuel cores:5
    ```

    - **cores** (required): Amount of Cores to deposit into Guild Vault (minimum: 1).
  </Tab>
</Tabs>

## How Pro Engine Works

1. **Community Fueling**: Anyone in the server can deposit personal Cores into the server's Guild Vault using `/engine fuel`.
2. **Automated Coverage**: As long as the Vault contains enough Cores, the server retains Pro Engine benefits automatically.
3. **Top Sponsors**: View the top contributors who fueled the server using `/engine vault`.
