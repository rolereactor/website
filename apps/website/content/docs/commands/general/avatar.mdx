## Usage Examples

1. Generate a basic avatar:
   ```bash
   /avatar prompt:cyberpunk hacker with neon hair
   ```
2. Generate with a specific art style:
   ```bash
   /avatar prompt:kawaii girl with pink cat ears art_style:chibi
   ```
3. The bot will generate your unique anime-style avatar using AI.

## Features

- **AI-Powered Generation:** Uses advanced AI to create unique anime-style avatars based on your text prompt.
- **Multiple Art Styles:** Choose from `manga`, `modern`, `retro`, `realistic`, `chibi`, or `lofi`.
- **Core Credit System:** Uses 1 Core credit per avatar generation (check balance with `/core balance`).
