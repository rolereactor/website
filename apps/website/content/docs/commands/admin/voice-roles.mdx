## Usage Examples

<Tabs items={["Disconnect", "Mute", "Deafen", "Move", "List All"]}>
  <Tab value="Disconnect">
    Auto-disconnect users with a role:
    ```bash
    /voice-roles disconnect add role:@MutedRole
    /voice-roles disconnect remove role:@MutedRole
    ```
  </Tab>
  <Tab value="Mute">
    Auto-mute users with a role:
    ```bash
    /voice-roles mute add role:@QuietRole
    /voice-roles mute remove role:@QuietRole
    ```
  </Tab>
  <Tab value="Deafen">
    Auto-deafen users with a role:
    ```bash
    /voice-roles deafen add role:@DeafenedRole
    /voice-roles deafen remove role:@DeafenedRole
    ```
  </Tab>
  <Tab value="Move">
    Auto-move users with a role to a voice channel:
    ```bash
    /voice-roles move add role:@MovedRole channel:#waiting-room
    /voice-roles move remove role:@MovedRole
    ```
  </Tab>
  <Tab value="List All">
    View all active voice control rules:
    ```bash
    /voice-roles list
    ```
  </Tab>
</Tabs>

## Permissions Required

<Callout type="info">
  - **Manage Roles** permission required to configure rules.
  - Bot requires **Move Members**, **Mute Members**, or **Deafen Members** permissions depending on the rule group.
</Callout>
