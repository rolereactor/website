## Subcommands

<Cards>
  <Card title="timeout" description="Timeout (mute) one or more users for a specified duration" />
  <Card title="warn" description="Issue a warning with automated history logging" />
  <Card title="ban" description="Ban one or more users from the server" />
  <Card title="kick" description="Kick one or more users from the server" />
  <Card title="unban" description="Unban previously banned users" />
  <Card title="purge" description="Bulk-delete messages from a channel (1-100)" />
  <Card title="history" description="View moderation history for a user or the entire server" />
  <Card title="remove-warn" description="Remove a specific warning from a user by case ID" />
  <Card title="list-bans" description="List all banned users in the server" />
  <Card title="timeouts" description="List all currently timed out members in the server" />
</Cards>

## Usage Examples

<Tabs items={["Timeout", "Warn & History", "Ban & Kick", "Purge", "List Timeouts"]}>
  <Tab value="Timeout">
    Timeout one or multiple users:

    ```bash
    /moderation timeout users:@user1,@user2 duration:1h reason:Spamming in main chat
    ```

    - Supports up to 15 users in a single command
    - Duration format: `10s`, `5m`, `1h`, `1d`, `1w` (maximum 28 days)
  </Tab>
  <Tab value="Warn & History">
    Warn a user or check moderation history:

    ```bash
    /moderation warn users:@user1 reason:Breaking rule #3
    /moderation history user:@user1
    /moderation remove-warn user:@user1 case-id:abc123
    ```
  </Tab>
  <Tab value="Ban & Kick">
    Ban, unban, or kick users:

    ```bash
    /moderation ban users:@user1 reason:Repeated violations delete-days:1
    /moderation unban users:123456789012345678
    /moderation kick users:@user1 reason:Inappropriate behavior
    /moderation list-bans
    ```
  </Tab>
  <Tab value="Purge">
    Bulk delete messages:

    ```bash
    /moderation purge amount:50
    ```
  </Tab>
  <Tab value="List Timeouts">
    View all currently timed-out members:

    ```bash
    /moderation timeouts
    ```
  </Tab>
</Tabs>

## Permissions Required

<Callout type="info">
  - **Moderate Members** — Required for timeout
  - **Ban Members** — Required for ban and unban
  - **Kick Members** — Required for kick
  - **Manage Messages** — Required for purge
</Callout>

## What You'll See

<Callout type="info">
  Confirmation embeds for each moderation action with details about who was moderated, case ID, reason, and duration. Actions are logged in the user's moderation history for future reference.
</Callout>

## Restrictions & Limits

<Callout type="warning">
  - **Role Hierarchy:** You can only moderate users with a lower role than yours. Server owners and bot accounts cannot be moderated.
  - **Duration Cap:** Timeouts have a maximum limit of 28 days.
  - **Purge Limit:** Discord only allows purging messages less than 14 days old.
</Callout>
