## Usage Examples

<Tabs items={["Create Bundle", "View & List", "Delete"]}>
  <Tab value="Create Bundle">
    Create a role bundle with space-separated roles:

    ```bash
    /role-bundle create name:StarterPack roles:@Gamer @Member "Community Supporter"
    ```

    - Role mentions, role names, and Role IDs are supported.
    - Role names with spaces must be wrapped in double quotes.
  </Tab>
  <Tab value="View & List">
    List all server bundles or view roles inside a specific bundle:

    ```bash
    /role-bundle list
    /role-bundle view name:StarterPack
    ```
  </Tab>
  <Tab value="Delete">
    Delete a bundle by name:

    ```bash
    /role-bundle delete name:StarterPack
    ```
  </Tab>
</Tabs>

## Integrating Bundles into Reaction Role Menus

Once a role bundle is created, you can use it directly inside `/role-reactions setup` or `/role-reactions update` by using the `bundle:` option or formatting:
```bash
/role-reactions setup title:Get Roles description:Click reaction to get all starter roles! bundle:StarterPack emoji:🎮
```

## Permissions Required

<Callout type="info">
  - **Manage Server** or **Manage Roles** permission required
</Callout>

## Limits

<Callout type="info">
  - **Free Tier:** Up to 5 roles per bundle.
  - **Pro Engine:** Up to 15 roles per bundle.
</Callout>
