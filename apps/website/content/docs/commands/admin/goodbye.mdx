## Placeholders

You can use these placeholders in your goodbye message:

- `{user}` - User mention
- `{user.name}` - Username
- `{user.tag}` - User tag
- `{server}` - Server name
- `{memberCount}` - Total member count (human members only)
- `{memberCount.ordinal}` - Ordinal member count (e.g., "1st", "2nd", "3rd")

## Usage Examples

<Tabs items={["Basic Setup", "Advanced Setup", "With Embed"]}>
  <Tab value="Basic Setup">
    Configure basic goodbye greetings:
    ```bash
    /goodbye setup channel:#goodbye message:**{user}** left the server! Thanks for being part of **{server}**! 👋
    ```
  </Tab>
  <Tab value="Advanced Setup">
    Custom message with member count placeholder:
    ```bash
    /goodbye setup channel:#goodbye message:Goodbye **{user.name}**! We now have {memberCount} members in **{server}**.
    ```
  </Tab>
  <Tab value="With Embed">
    Send goodbye messages as rich embeds:
    ```bash
    /goodbye setup channel:#goodbye embed:true message:**{user}** left **{server}**. We hope to see you again!
    ```
  </Tab>
</Tabs>

## Permissions Required

<Callout type="info">
  - **Manage Server** permission required to configure settings

## Note on Human-Only Member Counts

<Callout type="info">
  Member count placeholders strictly count human members, excluding bots for accurate community statistics.
</Callout>
