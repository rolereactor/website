## Usage Examples

<Tabs items={["Create", "Manage"]}>
  <Tab value="Create">
    Create a giveaway with required parameters:
    ```bash
    /giveaway create prize:Nitro winners:1 duration:24h
    ```
    Optional configuration filters:
    - `channel` — Channel to post the giveaway in (default: current channel)
    - `description` — Additional details or instructions
    - `required-role` — Specific role required to enter
    - `min-level` — Minimum XP level required to enter
    - `require-vote` — Require a top.gg vote in the last 12 hours (`true`/`false`)
    - `claim-period` — Hours winners have to claim their prize (integer, e.g. `24` or `48`)
    - `min-account-age` — Minimum Discord account age in days (integer)
    - `min-server-age` — Minimum server membership time in days (integer)
  </Tab>
  <Tab value="Manage">
    Manage existing giveaways:
    ```bash
    /giveaway list
    /giveaway end giveaway-id:abc123
    /giveaway reroll giveaway-id:abc123 winners:1
    /giveaway cancel giveaway-id:abc123
    /giveaway delete giveaway-id:abc123
    ```
  </Tab>
</Tabs>
