## Usage Examples

<Tabs items={["Setup", "Management", "Staff Tools"]}>
  <Tab value="Setup">
    Set up the ticket system:
    ```bash
    /ticket setup channel:#support title:Support description:Click to open a ticket
    ```
    Options:
    - `channel` — Channel where the panel embed will be created (required)
    - `title` — Custom panel title
    - `description` — Custom panel description
    - `color` — Select embed theme color (Primary, Success, Danger, Warning, Cyberpunk, etc.)
  </Tab>
  <Tab value="Management">
    Manage panels and system settings:
    ```bash
    /ticket info
    /ticket settings
    /ticket panel list
    /ticket panel delete panel-id:1
    ```
    The `/ticket settings` command opens an interactive dashboard to configure staff roles, ticket categories, and auto-archiving.
  </Tab>
  <Tab value="Staff Tools">
    Commands executed inside ticket channels:
    ```bash
    /ticket close reason:Issue resolved
    /ticket add member:@member
    /ticket remove member:@member
    /ticket transfer staff:@staff
    /ticket rename name:bug-report-101
    /ticket transcript ticket-id:1 format:html
    ```
    Transcript formats: `html` (Rich HTML), `json`, `md` (Markdown)
  </Tab>
</Tabs>

## Permissions Required

<Callout type="info">
  - **Manage Server** permission required for setup, info, and settings.
  - **Manage Messages** or Staff role required for add, remove, transfer, and rename tools.
</Callout>
