## Usage Examples

<Tabs items={["Settings", "Role Rewards", "Reward Mode"]}>
  <Tab value="Settings">
    Open the interactive XP settings dashboard:
    ```bash
    /xp settings
    ```
    The bot will display an interactive interface allowing you to toggle message XP, command XP, role XP, and voice XP.
  </Tab>
  <Tab value="Role Rewards">
    Manage role rewards for leveling up:
    ```bash
    /xp rewards add level:10 role:@ActiveMember
    /xp rewards remove level:10 role:@ActiveMember
    /xp rewards list
    ```
    When users reach the specified level, they automatically receive the reward role.
  </Tab>
  <Tab value="Reward Mode">
    Configure whether level roles stack or replace lower roles:
    ```bash
    /xp rewards mode mode:stack
    /xp rewards mode mode:replace
    ```
  </Tab>
</Tabs>
